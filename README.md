# 机器人街区 AI 未来商店 · 双世界商业实验

**v0.3** ｜ Vite + 原生 ES Modules + SVG ｜ 纯前端：无后端 / 无大模型 API / 无真实支付 / 无硬件控制

一个用于课程展示与概念验证的 2D 可视化实验：同一项「主人任务」，**左侧由人类顾客走进坂田机器人街区的实体门店购物**，**右侧由 AI 数字分身「小星」在线上智能体商店购物**。两个世界同屏并行、信息渠道不同、耗时尺度不同，最后由主人在「双世界汇合」区综合两边信息做决定。

---

## 快速开始

```bash
npm install
npm run dev      # 开发预览 http://localhost:5180/ （已对局域网开放）
npm test         # jsdom 端到端回归测试（38 项断言）
npm run build    # 生产构建到 dist/
```

运行后：选实验（A / B / C）→ 点「开始实验」→ 观察左右两栏并行 → 在底部「双世界汇合」区点「把线下体验反馈给小星」看推荐如何变化 → 选主人的最终决定。右侧还可切换「统一平台 / 独立站点」架构模式（只影响右侧）。

## 三个实验

| 编号 | 名称 | 线下（人类顾客） | 线上（小星） |
|---|---|---|---|
| A | 商品比较 | 到实体店看实物、试操作、问店员 | 查目录、按预算/功能/价格评分出推荐 |
| B | 发现新品 | 逛门店与机器人剧场，记录现场展示与活动 | 查各店新品，区分「目录已有」与「自上次访问后新增」 |
| C | 采购与体验决策 | 现场发现实物操作困难（线上无法获知） | 比对规格价格、校验预算与授权、提交建议 |

C 是核心演示：线下反馈写回评分 → 小星重新计算 → 推荐可能变化 → 主人拍板。

---

## 双世界的核心差异

| | 左栏：线下世界 | 右栏：线上世界 |
|---|---|---|
| 主体 | 人类顾客（黄衣 2D 小人） | AI 数字分身「小星」 |
| 场所 | 坂田机器人街区实体门店 | 智能体商店（结构化目录） |
| 信息 | 眼睛看、手摸、问人 | 目录字段、可解释评分 |
| 计时 | **分钟**（人类尺度） | **秒**（AI 尺度） |

## 设计边界（改代码前先读）

1. **小星没有线下机器人身体。** 不做具身、不做导航、不做抓取。线下移动的只有「人类顾客」这个示意角色。
2. **不接大模型。** 所有对话与推荐都由本地预设规则 / 模板生成，可解释、可复现。
3. **无真实交易。** 订单号为模拟（`simulated: true`），不联网、不支付。
4. **时间是教学模拟参数。** 线下「分钟」与线上「秒」是两个独立累加器，并非真实耗时。

---

## 两种线上架构模式

- **统一平台模式（platform）**：平台网关 `hub` 统一提供商店目录，小星经平台访问各店（`DISCOVER_STORES` / `PLATFORM_ISSUED`）。
- **独立站点模式（p2p）**：没有平台，小星逐家直连询问（`SELF_VERIFIED`）。

切换模式**只影响右侧线上路径**，左侧线下街区保持不变。

## 目录结构

```
├─ index.html              # 双栏布局：左 #street（线下）/ 右 #world（线上）
├─ vite.config.js          # 端口 5180、host 0.0.0.0、注入 window.__LAN_INFO__
├─ regression.test.mjs     # jsdom 端到端回归（npm test）
├─ data/
│  ├─ experiments.js       # 三个实验的任务定义、到访顺序、汇合反馈回路
│  ├─ street.js            # 街区实体点位 + 「门店 ↔ 线上商店」映射
│  ├─ stores.js            # 三家线上商店与店铺智能体话术
│  ├─ products.js          # 9 件商品（含 physical 实物体验字段）
│  ├─ tasks.js             # 任务类型 compare / discover / purchase
│  ├─ scenarios.js         # 主人偏好与场景配置
│  └─ architecture.js      # 两种架构模式、对比、免责声明
└─ src/
   ├─ main.js              # 编排器：双世界并行、汇合、反馈重算、模式切换
   ├─ agent.js             # 线上小星状态机 + 采购四阶段 + 授权校验
   ├─ human.js             # 线下人类顾客状态机（按分钟计时）
   ├─ world.js             # 线上世界 SVG 与小星移动
   ├─ world-street.js      # 线下街区 SVG 与人类顾客移动
   ├─ ui.js                # 全部 DOM 渲染（双日志、未来商店、决策区）
   ├─ scoring.js           # 可解释评分 + 运行时体验调整
   ├─ clock.js             # 可暂停时钟 wait() / clock.paused
   ├─ dialogue.js          # 微信风格对话文案
   ├─ protocol.js          # A2A/1.0 JSON 报文（仅线上展示）
   ├─ history.js           # 「上次访问」记录（localStorage）
   └─ style.css            # 双栏 / 未来商店 / 决策区样式
```

更多实现细节、扩展方法与踩坑记录见 **[HANDOFF.md](./HANDOFF.md)**。
